Responsive คืออะไร?

การออกแบบเว็บไซต์ให้ปรับขนาด
และรูปแบบตามหน้าจอของผู้ใช้งาน

Flexible Layout

ใช้โครงสร้างที่ยืดหยุ่น
เพื่อให้เนื้อหาปรับตามพื้นที่หน้าจอ

หลายขนาดหน้าจอ

เว็บไซต์ควรรองรับทั้ง
Desktop, Tablet และ Mobile

Media Query

CSS ที่ช่วยกำหนดรูปแบบ
ให้เหมาะกับขนาดหน้าจอแต่ละแบบ

Responsive Images

ทำให้รูปภาพสามารถปรับขนาด
ให้เหมาะกับพื้นที่ที่แสดงผล

ใช้งานง่ายทุกอุปกรณ์

ช่วยให้ผู้ใช้เข้าถึงเว็บไซต์
ได้สะดวกและอ่านง่ายมากขึ้น
